# Datheon Full Stack Web Development Internship

This repository contains three projects developed as part of my Full Stack Web Development Internship tasks.
These projects demonstrate my skills in frontend development, responsive design, JavaScript programming, and working with APIs.

## Projects

### 1. Personal Portfolio Website

A responsive personal portfolio website that introduces me, showcases my skills, and presents my projects and contact information.

**Technologies:** HTML, CSS, JavaScript.

### 2. Dynamic Task Manager & Productivity Tracker

A task management application that helps users organize tasks, track progress, and improve productivity through an interactive interface.

**Technologies:** HTML, CSS, JavaScript.

### 3. Weather Forecast Application

A responsive weather application that allows users to search for a city and view current weather conditions and forecast information using a weather API.

**Technologies:** HTML, CSS, JavaScript, Weather API.

## How to Run the Projects

1. Clone or download this repository.
2. Open the folder of the project you want to run.
3. Open `index.html` in your browser.
4. For the Weather Forecast application, configure a valid weather API key if required.
